Part 1: Library_DB
Q1. Set up a MongoDB database named "Library_DB".
js
use Library_DB
switched to db Library_DB

Q2. Create a collection named "books" within the "Library_DB" database.
The collection is created automatically when the first document is inserted (see Q3).

Q3. Insert at least 5 documents into the "books" collection.
js
db.books.insertMany([
  { title: "Atomic Habits",      author: "James Clear",      genre: "Self-Help", price: 550, availableCopies: 10 },
  { title: "The Alchemist",      author: "Paulo Coelho",     genre: "Fiction",   price: 350, availableCopies: 15 },
  { title: "Wings of Fire",      author: "A.P.J. Abdul Kalam", genre: "Biography", price: 299, availableCopies: 0 },
  { title: "The White Tiger",    author: "Aravind Adiga",    genre: "Fiction",   price: 450, availableCopies: 8 },
  { title: "Rich Dad Poor Dad",  author: "Robert Kiyosaki",  genre: "Finance",   price: 899, availableCopies: 5 }
])
{ acknowledged: true, insertedIds: { '0': ObjectId('...'), '1': ObjectId('...'), '2': ObjectId('...'), '3': ObjectId('...'), '4': ObjectId('...') } }

Q4. Ensure that each document has a unique identifier.
MongoDB adds a unique _id (ObjectId) to every document automatically, as seen in the output of Q3.

Q6. Find and display books whose price is between ₹300 and ₹800.
js
db.books.find({ price: { $gte: 300, $lte: 800 } })
{ title: 'Atomic Habits',   price: 550, ... }
{ title: 'The Alchemist',   price: 350, ... }
{ title: 'The White Tiger', price: 450, ... }

Q7. Find and display books belonging to a specific genre.
js

{ title: 'The Alchemist',   genre: 'Fiction', price: 350, availableCopies: 15, ... }
{ title: 'The White Tiger', genre: 'Fiction', price: 450, availableCopies: 8, ... }

Q8. Update the price of a particular book.
js
db.books.updateOne({ title: "The Alchemist" }, { $set: { price: 400 } })
{ acknowledged: true, matchedCount: 1, modifiedCount: 1, upsertedCount: 0 }

Q9. Increment the availableCopies of books that are currently in stock by 2.
js
db.books.updateMany({ availableCopies: { $gt: 0 } }, { $inc: { availableCopies: 2 } })
{ acknowledged: true, matchedCount: 4, modifiedCount: 4, upsertedCount: 0 }

Q10. Delete a book document from the collection.
js
db.books.deleteOne({ title: "Rich Dad Poor Dad" })
{ acknowledged: true, deletedCount: 1 }

Q11. Delete all books that have 0 availableCopies.
js
db.books.deleteMany({ availableCopies: 0 })
{ acknowledged: true, deletedCount: 1 }
